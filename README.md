## 🚀 Quick Execution Guide

### Running Node.js Experiments (6 to 12):
```bash
# Experiment 6: Console & Web Application
cd Exp-06-NodeApp
node console-app.js
node web-app.js

# Experiment 7: Events & Event Loop
cd Exp-07-Events
node events-demo.js
node event-loop-demo.js

# Experiment 8: File System
cd Exp-08-FS
node server.js

# Experiment 9: Web Module (Server & Client)
cd Exp-09-WebModule
node server.js
# In another terminal:
node client.js

# Experiment 10: Express Request & Response
cd Exp-10-Express
node server.js

# Experiment 11: Express GET & POST Form Handling
cd Exp-11-GetPost
node server.js

# Experiment 12: MongoDB CRUD Application
cd Exp-12-MongoDB
node crud-demo.js   # Terminal CRUD Demo
node server.js      # Web UI CRUD Demo on http://localhost:5000
```

### Running React.js Experiments (2 to 5):
```bash
# Navigate to the experiment directory:
cd Exp-02-Components  # or Exp-03-CSS, Exp-04-MUI, Exp-05-Themes

# Install dependencies (first time only):
npm install

# Start development server:
npm start
```
